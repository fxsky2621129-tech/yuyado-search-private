# 湯宿サーチ Android端末内版 v1.1

温泉・食事の条件で、自分が登録した宿を探す個人用HTMLアプリです。元のHTMLファイルをそのまま保管しています。

## 開き方

1. 自分のGitHubアカウントでこの非公開リポジトリを開きます。
2. [湯宿サーチのHTML](./yuyado-search-android-local-v1.1.html)を選び、ファイル画面の「Download raw file」（ダウンロード）から端末へ保存します。
3. 保存したHTMLを、端末内HTMLとJavaScriptに対応するブラウザーで開きます。Androidではファイル管理アプリから「アプリで開く」を選びます。機種・ブラウザーによってはローカルHTMLを開けない場合があります。

GitHubのファイル画面はソースコードの表示・ダウンロード用です。そのURLを開くだけではアプリは起動しません。GitHub Pagesは有効にしていません。

## 保存とバックアップ

- 宿・お気に入りは使用中のブラウザーのlocalStorageに保存します。GitHubへの自動保存や、端末間の同期はありません。
- 「＋ 宿を登録」→「JSONを書き出し」でバックアップできます。「JSONを読み込み」は現在の登録データを置き換えます。
- ブラウザーのデータ削除、機種変更、HTMLの移動・名前変更、別ブラウザーで開く前にJSONを書き出してください。ローカルファイルの保存領域はブラウザーにより扱いが異なります。
- 最初の4件は実在の宿ではないサンプルです。外部APIから宿情報や料金を取得する機能はありません。

## 非公開での利用

このリポジトリはPrivateで作成しています。公開サイトや共有相手は追加していません。端末にダウンロードしたHTMLにはログイン機能はないため、端末自体の画面ロックを利用してください。

アプリ自体は外部APIを使用しません。「公式サイト」「地図」を押すと外部サイトへ移動します。

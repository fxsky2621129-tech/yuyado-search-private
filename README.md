# 湯宿サーチ

[アプリを開く](https://fxsky2621129-tech.github.io/yuyado-search-private/)

## スマホでアプリとして使う

1. 上のリンクをAndroidのChromeで開きます。
2. 画面内の「アプリをインストール」、またはChromeの「︙」→「ホーム画面に追加」→「インストール」を選びます。
3. ホーム画面の「湯宿サーチ」アイコンから開けます。

iPhoneはSafariの共有メニュー→「ホーム画面に追加」を使います。メニューの名称は端末・ブラウザーによって異なります。

初回オンラインで開き「オフラインで開く準備ができました」と表示された後は、登録済みの宿の検索・編集をオフラインでも利用できます。公式サイト・地図への移動は通信が必要です。アプリストアやAPKからのインストールは不要です。

## データ

- サイトとソースコードは公開用です。登録した宿・メモ・お気に入りは、各端末のブラウザー内に保存します。自動同期やサーバーへの登録データ送信はありません。
- 「＋ 宿を登録」→「JSONを書き出し」でバックアップしてください。ブラウザーのデータを削除すると登録内容も消える場合があります。
- 旧端末内版からは、旧版でJSONを書き出し、新版の「JSONを読み込み」で移行します。読み込みは現在の登録データを置き換えます。
- 初期データ4件は架空のサンプルです。実在の宿や料金を自動取得する機能はありません。
- このアプリにログイン機能はありません。同じ端末・ブラウザーを使う人は保存データを開けます。

元の端末内版HTMLも保管しています。通常は上のアプリ用URLを利用してください。
